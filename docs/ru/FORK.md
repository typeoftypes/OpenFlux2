# О форке

Этот репозиторий - изменённый форк
[p1neappleXpress/OpenFlux](https://github.com/p1neappleXpress/OpenFlux).
Он сохраняет историю Git апстрима и распространяется по той же лицензии
GPL-3.0-or-later.

## Основные изменения в этом форке

- нативный Android-клиент на `VpnService` с интерфейсом в стиле Android 11 и
  вертикальной навигацией как в системных настройках телефона;
- второй режим подключения на Android, Прокси (SOCKS5), наряду с режимом
  туннеля, с опциональным доступом из локальной сети и SOCKS5-аутентификацией;
- зашифрованное хранение ссылки на документ и общего секрета через Android
  Keystore;
- опциональное сквозное шифрование транспорта AES-256-GCM с выводом ключа
  через scrypt, wire-совместимое с бинарниками exit node и клиента апстрима;
  оставьте ключ пустым, чтобы работать с обычной незашифрованной нодой
  апстрима;
- индикатор скорости загрузки/выгрузки в реальном времени в уведомлении о
  соединении;
- `--encryption-key-file` читает общий секрет из файла, доступного только
  root, а не из аргумента процесса - это не даёт секрету попасть в `ps`/
  список процессов;
- удаление нерабочего прототипа под iOS.

## Ветки

`main` остаётся wire-совместимой с текущими бинарниками exit node и клиента
апстрима. Отдельная ветка `experimental` несёт функции, которым нужна exit
node на коде именно этого форка (фреймированный транспортный протокол,
мультиплексирующий ping/DNS-relay трафик в зашифрованном канале): граф
пинга, отображение страны exit node и серверный DNS relay. Полное сравнение -
в [UPSTREAM_DIFF.md](UPSTREAM_DIFF.md).

Форк экспериментальный и никак не связан с Яндексом и не одобрен им.
