# Как контрибьютить

Контрибьюции приветствуются. Делайте изменения точечными и не коммитьте
собранные APK, бинарники, кэши сборки, ссылки на документы, ключи шифрования
или ключи подписи.

Перед тем как открыть pull request:

1. Прогоните `gofmt` по изменённым Go-файлам.
2. Прогоните `go test ./...`.
3. Для изменений в Android-приложении прогоните `./build_android_app.sh` и
   проверьте установку на Android 8 или новее.
4. Опишите влияние на совместимость протокола и безопасность при изменении
   чего-либо в `transport/`.
5. Проверьте `git diff --check` и просмотрите `git diff --cached` на предмет
   секретов.

Делая контрибьюцию, вы соглашаетесь, что она распространяется по лицензии
репозитория GPL-3.0-or-later.
